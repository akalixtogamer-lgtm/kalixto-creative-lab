# Checklist — Laboratório 01 · CSS Playground

Rode `npm start`, abra http://localhost:4200 e clique em **Abrir CSS Playground**.

## Para cada uma das 8 demos
Transitions · Keyframes · Transform · Hover · Floating · Perspective · Clip-path · Microinterações

- [ ] O botão principal (Executar) faz algo visível
- [ ] Mexer nos controles muda o efeito
- [ ] O código à direita/abaixo muda junto com os controles
- [ ] **Copiar** copia o código (cole num editor para conferir)
- [ ] **Reiniciar** volta tudo ao padrão
- [ ] A explicação e a dica fazem sentido para um aluno

## Navegação
- [ ] A faixa de botões troca de demo
- [ ] "Próxima demo" / "Demo anterior" funcionam
- [ ] Recarregar a página mantém a demo aberta (a demo fica na URL)
- [ ] Na Biblioteca, clicar num efeito do CSS abre a demo certa

## Celular (F12 → modo dispositivo)
- [ ] A faixa de demos rola para o lado
- [ ] Palco, controles, código e explicação aparecem um embaixo do outro
- [ ] Os sliders são fáceis de arrastar com o dedo

## Interface revisada
- [ ] Dashboard deixa claro por onde começar
- [ ] Labs "em breve" não parecem quebrados
