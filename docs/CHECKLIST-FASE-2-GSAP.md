# Checklist — Laboratório 02 · GSAP Studio

Rode `npm start`, abra http://localhost:4200 e clique em **GSAP Studio** no menu.

## Para cada uma das 7 demos
gsap.to() · gsap.from() · gsap.fromTo() · Timeline · Stagger · Easing · Controles de reprodução

- [ ] O botão principal executa a animação
- [ ] Mexer nos controles muda o resultado (e o código)
- [ ] **Copiar** copia o código
- [ ] **Reiniciar** volta tudo ao lugar
- [ ] Trocar de demo no meio da animação não deixa nada torto

## Específicos
- [ ] Easing: o gráfico muda ao trocar o tipo/direção e o ponto percorre a curva
- [ ] Timeline: a sobreposição faz os passos se encavalarem
- [ ] Stagger: "center", "edges" e "random" fazem ondas diferentes
- [ ] Player: Play, Pause, Reverse, Restart e a barra de progresso funcionam; a velocidade muda ao vivo

## Logo
- [ ] Logo aparece no menu, no Dashboard, na barra do celular e na aba do navegador (favicon)
- [ ] Página Design System → seção Marca

## Celular
- [ ] Demos cabem na tela; botões do player são fáceis de tocar
